# ד״ר רובוט – AI לנשות מערכת הבריאות

אפליקציית ווב סטטית בעברית (RTL מלא) ללימוד ושימוש בבינה מלאכותית, המיועדת לנשים שעובדות במערכת הבריאות:
**מזכירות רפואיות**, **מנהלות מרפאה** ו**מלוות רופאים**.

המטרה: לתת לכל משתמשת כלי מעשי שמייצר פרומפטים מוכנים לשימוש בכל כלי AI, לפי התפקיד שלה ולפי המשימה שהיא צריכה לבצע היום, בלי לסכן פרטיות של מטופלים.

## מה יש באתר

| עמוד | כתובת | תוכן |
|---|---|---|
| ראשי | `#/` | הסבר קצר, שלושה כרטיסי מסלול, קריאה לפעולה |
| מסלול | `#/track/secretary` · `#/track/manager` · `#/track/assistant` | 4–5 קטגוריות משימות לכל מסלול, 3–5 משימות בכל קטגוריה, כלי מומלץ |
| מחולל פרומפטים | `#/generator` | טופס בארבעה שלבים: מסלול ← משימה ← שדות ← פרומפט מובנה (תפקיד, הקשר, משימה, פורמט פלט, מגבלות). כפתור העתקה, שמירה כקובץ, והיסטוריה מקומית של 10 הפרומפטים האחרונים |
| איזה כלי AI לבחור | `#/tools` | השוואה פשוטה בין ChatGPT, Claude, Gemini ו-Copilot, עם המלצה לכל מסלול |
| בטיחות ופרטיות | `#/safety` | שמונה כללים, דוגמת "ככה / לא ככה", ורשימת "עצרי רגע" |

בנוסף, **באנר בטיחות בולט מוצג בכל עמוד** ומזהיר מהזנת פרטים מזהים של מטופלים, והטופס מתריע אוטומטית כשמזוהה בשדה משהו שנראה כמו תעודת זהות, טלפון, מייל או תאריך מלא.

אפשר לקשר ישירות למשימה, למשל:
`#/generator?track=secretary&cat=appointments&task=reminder`

## הרצה

אין תהליך בנייה ואין תלויות. כל הקבצים סטטיים.

```bash
# אפשרות א: לפתוח את index.html ישירות בדפדפן
# אפשרות ב: שרת מקומי
python3 -m http.server 8000
# ואז לגלוש אל http://localhost:8000
```

### פריסה ב-GitHub Pages

Settings ← Pages ← Source: "Deploy from a branch" ← הענף הראשי, תיקייה `/ (root)`.

## מבנה הקבצים

```
index.html      מעטפת האתר: כותרת, ניווט, באנר בטיחות, פוטר
css/style.css   עיצוב (RTL, רספונסיבי, נגיש)
js/data.js      כל התוכן: מסלולים, קטגוריות, משימות, שדות, כלים, כללי בטיחות
js/app.js       ניתוב פנימי, רינדור עמודים, מחולל הפרומפטים, היסטוריה מקומית
```

### עריכת תוכן

כל התוכן נמצא ב-`js/data.js`:

- **שם האתר**: הקבוע `SITE_NAME` בראש הקובץ.
- **הוספת משימה**: מוסיפים אובייקט למערך `tasks` של הקטגוריה המתאימה, עם `id`, `name`, `desc`, `goal` (ניסוח המשימה ל-AI), `fields` (רשימת שדות) ו-`defaultFormat`. שדות משותפים (טון, אורך, קהל, רקע, פורמט, שפה) זמינים דרך האובייקט `F`.
- **כלים והמלצות**: המערך `TOOLS` והאובייקט `TOOL_RECOMMENDATIONS`.
- **כללי בטיחות**: המערך `SAFETY_RULES`.

## פרטיות

האתר פועל כולו בדפדפן. שום מידע לא נשלח לשרת. ההיסטוריה נשמרת ב-`localStorage` של המכשיר בלבד וניתנת למחיקה בלחיצת כפתור.
